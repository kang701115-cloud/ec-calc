양액 계산기

양액만 K+Mg+Ca
µL mL
방울토마토 권장 범위 도움말

단계별 권장값

단계권장 EC권장 N:K
정식~활착0.7 ~ 0.91 : 1.0
생장기1.2 ~ 1.61 : 1.3 ~ 1.5
개화기1.8 ~ 2.41 : 1.5 ~ 1.8
착과·비대기2.5 ~ 3.11 : 2.0 ~ 2.3

입력 팁

- 목표 N, K는 비율값 기준 입력. 기본적으로 1.0 = N 100 ppm 기준으로 해석함.
- AB 합액의 Ca는 중량비 2.25%로 가정함.
- K, Mg, Ca(NO₃)₂는 모두 10 wt% 스톡 기준으로 출력함.
- K가 많아질수록 Mg 결핍 위험이 커져서 K:Mg 비를 같이 맞춤.
- 총 Ca가 목표보다 낮으면 Ca(NO₃)₂·4H₂O 10 wt% 스톡을 자동 추가함.
- 단, Ca(NO₃)₂의 EC 기여량은 목표 EC의 25%를 넘지 않게 제한함.
- Ca(NO₃)₂ 추가로 들어간 질산태 N은 N:K 계산에 반영됨.

현재 계산 로직 요약

1. 목표 EC와 목표 N:K를 기준으로 반복 계산 시작
2. K 필요량 추정 → Mg 자동 보정
3. AB 안의 Ca 계산
4. Ca가 목표보다 낮으면 Ca(NO₃)₂ 추가
5. 단, Ca(NO₃)₂의 EC 기여량은 목표 EC의 25%로 제한
6. Ca(NO₃)₂에서 늘어난 질산태 N을 반영해 유효 N 재계산
7. 남는 EC를 AB가 채움
